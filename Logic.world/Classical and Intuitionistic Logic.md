# Two Notions of Truth: Classical and Intuitionistic Logic

Every logic talks about truth in two ways, and the two must eventually agree:

- **Semantic truth**, written $\vDash$: $\varphi$ holds in every model (valuation, world).
- **Provability**, written $\vdash$: $\varphi$ can be derived by the inference rules.

In both classical and intuitionistic propositional logic, soundness and completeness hold, so

$$\vDash \varphi \iff \vdash \varphi$$

— the two notions coincide ("the same, actually"). What distinguishes the two logics is *which* formulas they validate:

- $P \to P$ is valid in both — uncontroversial.
- $P \lor \neg P$ (law of excluded middle, **LEM**) and $(\neg P \to P) \to P$ (**Clavius' law**, *consequentia mirabilis*) are valid classically but **not** intuitionistically — controversial.

## 1. Syntax

Fix a countably infinite set $\mathrm{Var}$ of propositional variables, written $P, Q, R, \dots$

**Definition (formulas).** The set of formulas is generated by the grammar

$$\varphi, \psi \ ::=\ P \ \mid\ \bot \ \mid\ (\varphi \land \psi) \ \mid\ (\varphi \lor \psi) \ \mid\ (\varphi \to \psi)$$

where $P \in \mathrm{Var}$; $\bot$ is falsum, and $\land$, $\lor$, $\to$ are conjunction, disjunction and implication. Negation is not primitive — it is an abbreviation:

$$\neg \varphi \ := \ \varphi \to \bot$$

The syntax is shared by both logics.

## 2. Classical semantics: valuations

**Definition (valuation).** A valuation is a function

$$v : \mathrm{Var} \to \{0, 1\}$$

($0$ = false, $1$ = true). A valuation is exactly one row of a truth table. Every valuation extends uniquely to a function on all formulas by the truth-table recursion:

$$v(\bot) = 0, \qquad v(\varphi \land \psi) = \min\!\big(v(\varphi),\, v(\psi)\big), \qquad v(\varphi \lor \psi) = \max\!\big(v(\varphi),\, v(\psi)\big)$$

$$v(\varphi \to \psi) = 0 \iff v(\varphi) = 1 \ \text{and} \ v(\psi) = 0$$

Write $v \vDash \varphi$ ("$v$ satisfies $\varphi$") iff $v(\varphi) = 1$. Unfolding the recursion, satisfaction is characterized by

$$v \vDash P \iff v(P) = 1, \qquad v \nvDash \bot,$$

$$v \vDash \varphi \land \psi \iff v \vDash \varphi \ \text{and} \ v \vDash \psi,$$

$$v \vDash \varphi \lor \psi \iff v \vDash \varphi \ \text{or} \ v \vDash \psi,$$

$$v \vDash \varphi \to \psi \iff v \nvDash \varphi \ \text{or} \ v \vDash \psi.$$

Since $\neg\varphi := \varphi \to \bot$ and $v \nvDash \bot$ always, this gives

$$v \vDash \neg\varphi \iff v \nvDash \varphi.$$

Classically, "$\neg\varphi$ holds" and "$\varphi$ is false" are the same thing.

**Definition (validity / tautology).**

$$\vDash \varphi \iff v \vDash \varphi \ \text{for every valuation} \ v$$

("true under every valuation": all rows of the truth table evaluate to 1).

**Definition (semantic entailment).** For a set of formulas $\Gamma$:

$$\Gamma \vDash \varphi \iff \text{for every } v, \quad \big(v \vDash \psi \ \text{for all} \ \psi \in \Gamma\big) \ \implies \ v \vDash \varphi$$

*Example.* $\vDash P \to (P \lor Q)$: on each of the four rows of the truth table, $P \to (P \lor Q)$ evaluates to 1.

## 3. Natural deduction: the proof system shared by both logics

Judgments are sequents $\Gamma \vdash \varphi$, read "from the assumptions $\Gamma$ one can prove $\varphi$". Here $\Gamma$ is a **finite set of formulas** (the context); we write $\Gamma, \varphi$ for $\Gamma \cup \{\varphi\}$. Every rule carries the context $\Gamma$ explicitly because rules such as $\to$-introduction **discharge** an assumption, and the derivation must record exactly which assumptions its conclusion still depends on.

**Assumption**

$$\frac{}{\Gamma \vdash \varphi} \quad (\varphi \in \Gamma)$$

**Conjunction**

$$\frac{\Gamma \vdash \varphi \quad \Gamma \vdash \psi}{\Gamma \vdash \varphi \land \psi} \qquad \frac{\Gamma \vdash \varphi \land \psi}{\Gamma \vdash \varphi} \qquad \frac{\Gamma \vdash \varphi \land \psi}{\Gamma \vdash \psi}$$

**Disjunction**

$$\frac{\Gamma \vdash \varphi}{\Gamma \vdash \varphi \lor \psi} \qquad \frac{\Gamma \vdash \psi}{\Gamma \vdash \varphi \lor \psi} \qquad \frac{\Gamma \vdash \varphi \lor \psi \quad \Gamma, \varphi \vdash \chi \quad \Gamma, \psi \vdash \chi}{\Gamma \vdash \chi}$$

**Implication**

$$\frac{\Gamma, \varphi \vdash \psi}{\Gamma \vdash \varphi \to \psi} \qquad \frac{\Gamma \vdash \varphi \to \psi \quad \Gamma \vdash \varphi}{\Gamma \vdash \psi}$$

**Ex falso (explosion)**

$$\frac{\Gamma \vdash \bot}{\Gamma \vdash \varphi}$$

Since $\neg\varphi := \varphi \to \bot$, the negation rules are instances of the implication rules:

$$\frac{\Gamma, \varphi \vdash \bot}{\Gamma \vdash \neg\varphi} \ (\neg\mathrm{I}) \qquad\qquad \frac{\Gamma \vdash \varphi \quad \Gamma \vdash \neg\varphi}{\Gamma \vdash \bot} \ (\neg\mathrm{E})$$

Beware the rule that is **not** derivable:

$$\frac{\Gamma, \neg\varphi \vdash \bot}{\Gamma \vdash \varphi} \qquad (\text{reductio ad absurdum}, \ \mathrm{RAA})$$

From $\Gamma, \neg\varphi \vdash \bot$, the system only yields $\Gamma \vdash \neg\neg\varphi$ (via $\neg$I). Intuitionistically, "not not" is weaker than "yes".

*Example.* The identity principle is provable with no assumptions:

$$\frac{\dfrac{}{P \vdash P} \ (\text{assumption})}{\varnothing \vdash P \to P} \ (\to\mathrm{I})$$

**Definition (intuitionistic provability).** $\vdash \varphi$ iff there is a derivation of $\varnothing \vdash \varphi$ from the rules above. This system is intuitionistic natural deduction, **NJ**.

## 4. Classical provability: NJ + LEM

**Definition.** Classical natural deduction **NK** is NJ plus the axiom schema of excluded middle:

$$\frac{}{\Gamma \vdash \varphi \lor \neg\varphi} \ (\mathrm{LEM})$$

Write $\vdash_c \varphi$ for derivability of $\varnothing \vdash \varphi$ in NK.

**Theorem (LEM implies RAA).** In NK:

$$\frac{\Gamma, \neg\varphi \vdash \bot}{\Gamma \vdash \varphi}$$

*Proof.* From $\Gamma, \neg\varphi \vdash \bot$, $\to$I yields $\Gamma \vdash \neg\varphi \to \bot$, i.e. $\Gamma \vdash \neg\neg\varphi$. By LEM, $\Gamma \vdash \varphi \lor \neg\varphi$. Applying $\lor$E: in the case $\varphi$ we are done; in the case $\neg\varphi$, the premise together with ex falso gives $\Gamma, \neg\varphi \vdash \varphi$. Both cases yield $\varphi$, hence $\Gamma \vdash \varphi$. $\square$

**Theorem (the classical principles are equivalent).** Over NJ, the following are interderivable:

1. **LEM**: $\varphi \lor \neg\varphi$;
2. **DNE** (double negation elimination): $\neg\neg\varphi \to \varphi$;
3. **RAA**: from $\Gamma, \neg\varphi \vdash \bot$ infer $\Gamma \vdash \varphi$;
4. **Clavius' law**: $(\neg\varphi \to \varphi) \to \varphi$.

*Sketch.* (1) $\Rightarrow$ (3): the theorem above. (3) $\Rightarrow$ (2): from $\neg\neg\varphi$ (i.e. $\neg\varphi \to \bot$) and $\neg\varphi$, $\to$E gives $\bot$, so RAA (discharging $\neg\varphi$) yields $\varphi$; hence $\neg\neg\varphi \to \varphi$. (2) $\Rightarrow$ (1): NJ proves $\neg\neg(\varphi \lor \neg\varphi)$ — assume $\neg(\varphi \lor \neg\varphi)$; if $\varphi$ holds, then $\varphi \lor \neg\varphi$, contradiction, so $\neg\varphi$; but then $\varphi \lor \neg\varphi$ again, contradiction; discharging the assumption gives $\neg\neg(\varphi \lor \neg\varphi)$ — and DNE applied to $\varphi \lor \neg\varphi$ yields LEM. (1) $\Rightarrow$ (4): assume $\neg\varphi \to \varphi$; by LEM, $\varphi \lor \neg\varphi$; the case $\varphi$ is trivial, and in the case $\neg\varphi$, $\to$E gives $\varphi$; so $\varphi$, and $\to$I yields Clavius' law. (4) $\Rightarrow$ (3): from $\Gamma, \neg\varphi \vdash \bot$, ex falso gives $\Gamma, \neg\varphi \vdash \varphi$, so $\Gamma \vdash \neg\varphi \to \varphi$ by $\to$I; Clavius' law then gives $\Gamma \vdash \varphi$. $\square$

## 5. Soundness and completeness (classical)

**Theorem.** For every set of formulas $\Gamma$:

$$\Gamma \vdash_c \varphi \iff \Gamma \vDash \varphi$$

In particular, $\vdash_c \varphi \iff \vDash \varphi$: a formula is provable from NJ + LEM exactly when it is true under every valuation. (Soundness: all rules preserve truth under any valuation. Completeness: every tautology has an NK proof.) This is the arrow in the notes: "$\vDash \varphi$ … the same, actually … $\vdash \varphi$".

## 6. Intuitionistic semantics: Kripke models

A classical valuation is a single static snapshot. Intuitionistically, truth is knowledge that grows over time: a **world** is a state of knowledge, and later worlds may know more; once something is known, it stays known.

**Definition (Kripke model).** A Kripke model is a triple $(W, \leq, V)$, where

- $W \neq \varnothing$ is a set of **worlds**;
- $\leq$ is a reflexive and transitive relation on $W$ (a preorder): $w \leq w'$ means "$w'$ is a future world of $w$";
- $V : \mathrm{Var} \to \mathcal{P}(W)$ is a **monotone** valuation: if $w \in V(P)$ and $w \leq w'$, then $w' \in V(P)$ — if $P$ is true in a world, it remains true in all later worlds.

**Definition (forcing).** $w \vDash \varphi$ ("$w$ forces $\varphi$") is defined by recursion on $\varphi$:

$$w \vDash P \iff w \in V(P), \qquad w \nvDash \bot,$$

$$w \vDash \varphi \land \psi \iff w \vDash \varphi \ \text{and} \ w \vDash \psi,$$

$$w \vDash \varphi \lor \psi \iff w \vDash \varphi \ \text{or} \ w \vDash \psi,$$

$$w \vDash \varphi \to \psi \iff \text{for all } w' \geq w, \quad w' \vDash \varphi \ \implies \ w' \vDash \psi.$$

An implication is asserted at $w$ only if it holds now and in every future world. Negation is the case $\neg\varphi := \varphi \to \bot$ (and no world forces $\bot$):

$$w \vDash \neg\varphi \iff \text{for all } w' \geq w, \quad w' \nvDash \varphi.$$

**Lemma (persistence).** If $w \vDash \varphi$ and $w \leq w'$, then $w' \vDash \varphi$. (Induction on $\varphi$; the base case is the monotonicity of $V$.)

**Definition (validity).**

$$M \vDash \varphi \iff w \vDash \varphi \ \text{for every} \ w \in W,$$

$$\vDash \varphi \iff M \vDash \varphi \ \text{for every Kripke model} \ M,$$

and, for a finite set $\Gamma$ of formulas,

$$\Gamma \vDash \varphi \iff \text{for all } M \text{ and } w, \quad \big(w \vDash \psi \ \text{for all} \ \psi \in \Gamma\big) \ \implies \ w \vDash \varphi.$$

**Theorem (soundness and completeness, Kripke).** For finite $\Gamma$:

$$\Gamma \vdash \varphi \iff \Gamma \vDash \varphi$$

In particular, $\vdash \varphi \iff \vDash \varphi$: the intuitionistically provable formulas are exactly those forced at every world of every Kripke model.

## 7. Countermodels

**Example 1: LEM is not intuitionistically valid.** Take $W = \{w_0, w_1, w_2\}$ with $w_0 \leq w_1$, $w_0 \leq w_2$, and $V(P) = \{w_1\}$.

- $w_0 \nvDash P$ ($P$ is not yet verified at $w_0$);
- $w_0 \nvDash \neg P$, since the future world $w_1 \geq w_0$ forces $P$;
- therefore $w_0 \nvDash P \lor \neg P$, and so $\nvDash P \lor \neg P$. $\square$

(Note that $w_1 \vDash P$ and $w_2 \vDash \neg P$: at $w_0$ the formula $P$ is still undecided.)

**Example 2: Clavius' law is not intuitionistically valid.** Take $W = \{w_0, w_1\}$ with $w_0 \leq w_1$, and $V(P) = \{w_1\}$.

No world forces $\neg P$: $w_1 \nvDash \neg P$ because $w_1 \vDash P$, and hence also $w_0 \nvDash \neg P$. Therefore every world vacuously forces $\neg P \to P$. But $w_0 \nvDash P$. Hence $w_0 \nvDash (\neg P \to P) \to P$, and so $\nvDash (\neg P \to P) \to P$. $\square$

The same model also refutes DNE: $w_0 \vDash \neg\neg P$ (vacuously), yet $w_0 \nvDash P$.

## 8. Reading the clauses

**Three states at a world.** At a world $w$, a formula can be in exactly one of three states:

1. **verified**: $w \vDash P$ — we have a proof of $P$ now;
2. **refuted**: $w \vDash \neg P$ — no future world can ever verify $P$ (a verification would produce $\bot$);
3. **undecided**: $w \nvDash P$ and $w \nvDash \neg P$ — no proof yet, but some future world might verify $P$.

Classically only states 1 and 2 exist, so $P \lor \neg P$ always holds. Intuitionistically, $w \nvDash \varphi$ means merely "no evidence yet", whereas $w \vDash \neg\varphi$ is the strong claim "evidence that $\varphi$ can never be established". Hence $w \vDash \neg\varphi \implies w \nvDash \varphi$ always, but not conversely. LEM fails exactly at worlds where some formula is undecided: to assert $\varphi \lor \psi$ one must be able to name a disjunct *now*.

**One-world collapse.** If $W = \{w_0\}$ is a singleton, the future clauses collapse:

$$w_0 \vDash \neg\varphi \iff w_0 \nvDash \varphi, \qquad w_0 \vDash \varphi \to \psi \iff \big(w_0 \nvDash \varphi \ \text{or} \ w_0 \vDash \psi\big),$$

and forcing becomes exactly the classical truth table: a classical valuation *is* a one-world Kripke model. Intuitionistic phenomena need a nontrivial future.

**Double negation.** NJ proves $\varphi \to \neg\neg\varphi$, but not $\neg\neg\varphi \to \varphi$; and it proves $\neg\neg(\varphi \lor \neg\varphi)$, but not $\varphi \lor \neg\varphi$. "No contradiction" is not a construction.

## 9. The trade-off

- **Intuitionistic logic**: nice proof system (pure natural deduction, symmetric introduction/elimination rules) + crazy semantics (Kripke models, forcing over preorders).
- **Classical logic**: poor proof system (NJ plus the ad-hoc LEM/RAA rule) + nice semantics (two-valued truth tables).

In both logics soundness and completeness hold, so $\vDash$ and $\vdash$ describe the same set of formulas — "the same, actually". The difference is only where the burden lies: classical logic pays in the proof system, intuitionistic logic pays in the semantics.
